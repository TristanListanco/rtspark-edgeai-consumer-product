# data/

- `PROTOCOL.md`: capture procedure, sampling rates, window length, label definitions (M4)
- `manifest.csv`: one row per recording session: file, session, label, anonymized participant ID, date, location, rates, split, notes (M4)
- `EXCLUSIONS.md`: every dropped window/reading and why (M4)
- `raw/`: local captures, **gitignored** (may hold participant info). Commit only anonymized samples.
